# Анализ ошибок модели Orbit-NLU (Baseline)

**Дата:** 17.12.2025
**Модель:** Llama-3.1-8B-Instruct (LoRA r=16)
**Выборка:** 50 тестовых примеров

## 1. Общая статистика
*   **Total Samples:** 50
*   **Exact Match Accuracy:** 50.00%
*   **JSON Validity:** ~84% (8 примеров с Syntax Error)

## 2. Распределение ошибок (Top Patterns)
| Тип ошибки / Поле | Количество | Комментарий |
|-------------------|------------|-------------|
| **Wrong Value: altitude** | 11 | Модель пишет число без единиц измерения (напр. "1000" вместо "<1000 км"). |
| **Wrong Value: status** | 8 | **Критично:** Ошибка в датасете. Модель верно определяет "неактивен", но в GT стоит "активен". |
| **JSON Syntax / Empty** | 8 | Модель возвращает пустой JSON `{}` на некоторые вопросы (особенно начинающиеся с "Существуют ли..."). |
| **Hallucination: status** | 8 | Модель добавляет `status: "активен"`, если пользователь явно не указал статус (bias). |
| **Missing Slot: orbitType**| 6 | Не распознает сложные описания орбит (например, "средняя околоземная" -> "с"). |

## 3. Примеры ошибок

| Prompt | GT JSON (Эталон) | Predicted JSON (Модель) | Анализ |
|--------|------------------|-------------------------|--------|
| "Подбери неработающий 1 спутник..." | `"status": "активен"` | `"status": "неактивен"` | **Ошибка разметки.** Модель права, GT неверен. |
| "высоты ниже 1000 км" | `"altitude": "<1000 км"` | `"altitude": "1000"` | Потерян знак неравенства и единицы измерения. |
| "Покажи 7 спутники..." | `{...}` | `{}` | Syntax Error. Модель не сгенерировала JSON (пустой ответ). |
| "средней околоземной орбите" | `"orbitType": "MEO"` | `"altitude": "с"` | Галлюцинация. "с" (средняя) попало в altitude вместо маппинга в MEO. |
| "массой 29 кг для северный полюса" | `"coverage": "Арктика"` | *coverage отсутствует* | Missing Slot. Не сработал NER для "северный полюс" -> "Арктика". |

## 4. Выводы и Гипотезы

### Выявленные проблемы:
1.  **Грязные данные (Status):** В обучающей выборке перепутаны метки для статуса "неактивен". Это занижает метрику Accuracy примерно на 15%.
2.  **Форматирование (Altitude):** Модель ленится писать "км" и знаки "<", ">". Требуется ужесточение промпта или пост-процессинг.
3.  **Пустые ответы (Syntax):** 16% запросов не обрабатываются. Возможно, модель слишком рано останавливает генерацию (EOS token issue) или не понимает вопросительные формулировки.

### План действий (Гиперпараметры):
В следующем этапе (Grid Search) мы попытаемся исправить **Syntax Errors** и улучшить **Slot Filling**, варьируя параметры:
*   **Rank (r):** Увеличение `r` может помочь модели лучше запомнить связь "северный полюс" -> "Арктика".
*   **Learning Rate:** Корректировка LR может помочь избежать "забывания" формата JSON.
*   **Weight Decay:** Добавление регуляризации может снизить количество галлюцинаций статуса.
